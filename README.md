## How I work

- **Plan before code:** every change starts as a plan I question before approving
- **Never hand-edit:** I tell the agent what's wrong instead
- **Done means verified:** tests pass and I've seen the output
- **Least privilege:** agents get read-only access unless a human approves more
- **Public data only:** every project uses open, public data
